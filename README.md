## 📖 About The Project

**DigiTools** is a modern storefront interface which is designed for creators, professionals, and businesses to browse and purchase premium digital tools. From AI powered assets to productivity software, DigiTools provides a seamless browsing and shopping experience. 

Built with performance and user interface in mind. This project features a fully responsive landing page, transparent pricing tiers, and a functional cart system to manage digital purchases.

---

##  Top 3 Features

1.  **Dynamic Shopping Cart System**
   Users can seamlessly toggle between the product catalog and their cart. Items can be added or removed on real time updates and automatic price calculations before checkout.

2.  **Interactive Toast Notifications**
   Used `react-toastify` to provide instant, satisfying visual feedback. Users get notified immediately when items are successfully added to the cart, removed, or if an item is already in their cart.

3.  **Pixel-Perfect Responsive UI**
   Crafted with a mobile first approach. From the collapsible hamburger navigation to the dynamic product grids and pricing cards, the layout adapts beautifully to any screen size.

---

##  Built With

This project was built using modern web development standards and libraries:

*   **[React.js](https://reactjs.org/)** - For building the interactive user interface and managing component state (`useState`).
*   **[Tailwind CSS](https://tailwindcss.com/)** - For rapid, utility-first styling and responsive design without leaving the markup.
*   **[React Toastify](https://fkhadra.github.io/react-toastify/)** - For easy, customizable alert notifications.
*   **JSON Data Management** - Local `.json` mapping for scalable product rendering.
