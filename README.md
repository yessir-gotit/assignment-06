# 🛠️ DigiTools

**DigiTools** is a premium storefront interface designed for creators, professionals, and businesses to discover and acquire high-quality digital assets. From AI-powered tools to productivity software, DigiTools offers a sleek, modern, and high-performance shopping experience.

## 📖 About The Project

DigiTools provides a seamless browsing experience for digital shoppers. Built with a focus on performance and clean UI/UX, the project features a fully responsive landing page, transparent pricing tiers, and a functional cart system. 

The goal of this project was to create a "no-friction" environment where users can quickly identify the tools they need and manage their selections effortlessly.

---

## ✨ Top 3 Features

* **🛒 Dynamic Shopping Cart System:** Users can toggle between the product catalog and their cart. Features real-time updates for adding/removing items and automatic total price calculations.
* **🔔 Interactive Toast Notifications:** Integrated `react-toastify` to provide instant visual feedback. Users are notified when items are added, removed, or if a duplicate entry is attempted.
* **📱 Pixel-Perfect Responsive UI:** A mobile-first approach ensuring the collapsible navigation, product grids, and pricing cards adapt beautifully to any device.

---

## 🛠️ Built With

* **React.js:** For building a component-based UI and managing application state via `useState`.
* **Tailwind CSS:** For rapid, utility-first styling and a consistent design system.
* **React Toastify:** For elegant and non-intrusive user notifications.
* **JSON Data:** Utilizing local `.json` mapping for scalable and organized product rendering.


## 🚀 Getting Started

To get a local copy up and running, follow these steps:


### Installation

1.  **Clone the repo:**
    ```bash
    git clone https://github.com/yessir-gotit/Digitools.git
    ```
2.  **Install NPM packages:**
    ```bash
    npm install
    ```
3.  **Start the development server:**
    ```bash
    npm run dev
    ```
